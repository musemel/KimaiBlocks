# 操作ガイド

`dist\KimaiBlocks.exe` をダブルクリックして起動します（以前の版を終了してから起動してください）。.NET 10 Desktop Runtime / WPFを使うC#アプリです。Kimai接続専用です。保存済みの設定で起動時に自動接続します。

## Kimai接続

1. 右上の「メニュー → 設定」をクリックします。
2. KimaiのURL（例: `https://kimai.example.com`、サブディレクトリにも対応）を入力します。HTTPのテスト環境では「この接続先でHTTPを許可」をチェックします。URLを変更するとチェックが外れます。
3. Kimaiのユーザープロフィールで作成したAPIトークンを入力します。旧版のみ「旧認証方式」を選びます。通常のログインパスワードは使いません。
4. 「保存して接続」で、自分の週の実績とアクセス可能なプロジェクト・アクティビティを取得します。

接続後の追加・移動・サイズ変更・詳細編集・削除は、既定で60秒ごとにまとめてKimaiへ保存します。同じ実績への連続編集は最後の状態だけを送信し、未送信の作成を削除した場合は通信しません。保存間隔は設定で10〜3600秒に変更できます。削除は確認付きです。「今すぐ保存」、週の切り替え、再読込、終了時にも未保存分を保存します。未変更時の定期通信はありません。「再読込」は一覧キャッシュも更新します。フォルダ分類・表示選択・お気に入りはこのクライアントの設定です。

- 時刻は **Kimaiユーザーのタイムゾーン** で表示・入力します。Windowsの時刻設定へは変換しません。
- 未来の実績も送信できますが、Kimai側の設定・権限で拒否された場合はエラーになります。
- 「請求対象」を詳細編集で指定できます。既存のタグ・単価は更新時に保持します。
- プロジェクトとアクティビティにはIDを併記して、同名の項目を区別します。共通アクティビティは利用可能なプロジェクトに表示します。
- エクスポート済み、計測中、休憩付き、日またぎ、5分単位以外の実績は読み取り専用です。変更はKimai側で行ってください。日またぎは日ごとに分割表示します。計測中は開始位置に5分の目印で表示し、ライブ計測はしません。
- 読み取り専用レコードを含む週合計は画面上のブロック長の合計です。休憩・秒単位・計測中の正確な集計はKimaiで確認してください。
- 編集前にサーバー上の主要項目と比較します。ただし比較後から更新までの同時編集を完全に排他制御するものではありません。
- 保存失敗時はエラーダイアログを表示し、未保存変更を保持して定期保存を一時停止します。保存できるまで通常の終了を阻止します。「今すぐ保存」または「再読込」で復旧してください。起動・読込失敗時もダイアログを表示し、「再読込」で再試行できます。
- サーバーで成功して応答だけ失われた可能性がある場合は自動再送しません。「再読込」で照合し、判定できない場合はユーザーに再送の確認を求めます。強制終了やOS停止を完全に阻止するものではありません。送信途中の情報もキャッシュに記録します。
- HTTPSを既定とし、明示的に許可した接続先だけHTTPも使えます。HTTPではトークンとデータが暗号化されません。自己署名証明書を無条件に許可せず、リダイレクト先への認証情報の転送もしません。

## 操作

- 設定は右上の「メニュー → 設定」にあります。「カレンダーに土日を表示」をオフにすると月〜金の5列になります。非表示の土日の実績も週統計には含まれます。休日の入力禁止とは独立した表示設定です。
- 右の統計パネルは右上の「×」で閉じ、「メニュー → 右の統計パネルを表示／非表示」で再表示できます。表示状態は保存されます。
- 上部の表示期間をクリックすると週選択カレンダーが開きます。日付を選び「この週を表示」で、その日を含む月曜始まりの週へ移動します。

- ブロックの時刻の後ろに時間換算（例: `09:00–09:30  0.5h`）を表示します。小さいブロックで表示が切れる場合はツールチップで確認できます。時間換算は小数2桁までです。
- 右側の統計パネルは「週」「日」タブで切り替えます。週は合計・日別・プロジェクト別、日は合計・プロジェクト別・アクティビティ別を表示します。日付見出しや週の日別行をクリックすると、その日の統計を開きます。ブロック選択でも対象日が変わります。
- 統計は読込済みのブロックを集計し、未保存・未来の実績と重複時間を含みます。表示プロジェクトの選択は統計の対象を変更しません。休憩・計測中などを含む正確な請求時間はKimai側で確認してください。
- 左の「表示プロジェクトを選択…」を開き、別ダイアログの検索付きリストで表示プロジェクトを選択。検索しても選択は保持されます（登録済み実績は非表示になりません）。リストはスクロールでき、表示要素を再利用します。
- 左側は「フォルダ → プロジェクト → アクティビティ」のツリー。矢印で開閉し、作業検索・お気に入りで絞り込めます。検索中は一致する項目を展開します。
- ツリーの右クリックでフォルダ追加。フォルダ自身の右クリックで削除。削除しても中のプロジェクト・実績は消えず、プロジェクトはフォルダ外へ戻ります。
- プロジェクト名をフォルダ名へドラッグして分類。「プロジェクト（フォルダ外）」へドロップすると分類を解除します。フォルダは一階層です。
- アクティビティ名をカレンダーへドラッグして実績を作成。☆でお気に入り登録。フォルダ分類と通常表示の開閉状態も保存します。
- 作業項目の文字部分を週カレンダーへドラッグすると1時間の実績を作成（23時以降は当日24:00まで）。
- ブロック中央をドラッグして移動。上下端（短い枠では上下各1/4）をドラッグして時間変更。
- 5分単位で操作。日付移動は上部の矢印。未来の週も入力できます。
- ダブルクリックで詳細編集。右クリックまたは選択してDeleteで削除。
- 重なる実績は横に並べます。時間が短い場合はマウスを合わせて詳細表示。

## 休日・休み時間

「メニュー → 休日・休み時間」または「設定」から指定します。

- 毎週の休日（曜日）、追加の休業日（`yyyy-MM-dd`）、毎日の休み時間（`12:00-13:00`、複数行）を設定できます。休み時間は5分単位、同日内で終了24:00までです。日またぎの休みは2区間に分けてください。
- 初期値は土日と12:00〜13:00を暗色表示し、入力禁止はオフです。暗色表示と入力禁止は独立して切り替えられます。
- 入力禁止時は、新規作成・移動・サイズ変更・日時編集が禁止時間と一部でも重なると元に戻します。既存実績の表示・削除・時刻を変えないメモ編集はできます。既存の保存待ち変更には遡及適用しません。
- 時刻はKimaiユーザーのタイムゾーン基準です。祝日カレンダーの自動取得はありません。この制限は本クライアント内だけで適用します。

## プロジェクト追加

「メニュー → プロジェクト追加」から、追加先の顧客とクライアントの表示フォルダを選択します。顧客は入力検索できます。プロジェクト名、説明、請求対象を設定できます。

- グローバルアクティビティを必ず有効にします。プロジェクト専用アクティビティは作成しません。
- 確認チェック、内容確認、最終確認の後に即時作成します。実績の定期保存とは別の操作です。
- 同じ顧客の同名プロジェクトは作成前に検出します。結果が不明の場合は自動再送せず、画面を閉じて再読込するよう案内します。
- 作成にはKimai側の権限が必要です。フォルダ分類はローカル設定であり、Kimai上の所属先は選択した顧客です。

## 保存

`%LOCALAPPDATA%\KimaiBlocks` 内のURLとKimaiユーザーIDごとの `kimai-<hash>.json` に画面設定・読込済み実績・未保存変更を保存します。直前の状態は `.bak` に残します。旧ローカルモードの `state.json` は使用しません。

プロジェクト・アクティビティ一覧は `.catalog` にキャッシュし、認証したユーザーが一致する場合に利用します。有効期間は既定60分（設定で1〜1440分）。実績は起動時に取得し、キャッシュは読込中の表示と未保存変更の復元に利用します。新しいプロジェクトは折りたたみ、アクティビティを展開時に生成します。検索は入力停止から250ms後に実行します。

接続先・保存間隔・キャッシュ期間は `connection.json`。APIトークンはWindows DPAPIで現在のWindowsユーザー向けに暗号化して保存します。実績キャッシュ自体は暗号化されません。

## 現段階の制限

- テスト環境（Kimai 2.67.0）で、認証・一覧取得・過去と未来の5分実績の作成・更新・読込・削除を確認済みです。別バージョンや独自必須項目がある環境では調整が必要になる場合があります。
- Windows画面から、アクティビティのドラッグによる作成、5分へのサイズ変更、5分移動とサーバー保存を確認済みです。
- 日をまたぐ実績は日ごとに分割して入力してください。
- ドラッグ中の自動スクロール、複数選択、Undoは未実装。
- 101件のプロジェクトがある実サーバーで自動接続と選択ダイアログを確認済みです。大量実績の負荷計測は未実施です。

## ビルドと確認

PowerShellで `./Build.ps1`。.NET 10 SDKでビルドします。Visual Studioでは `KimaiBlocks.csproj` を開いて開発できます。NuGet依存は `MarkZither.KimaiDotNet.ApiClient` 1.0.0です。
`dist\KimaiBlocks.exe --self-test` は日付・操作領域・旧保存形式に加え、実際のSDKと模擬HTTP通信で、認証、プロジェクト別アクティビティ、日時形式、作成・更新・削除、ページ取得、競合検知、通信失敗時の非再送を検証します。実サーバーへの通信はしません。
`dist\KimaiBlocks.exe --sync-test` は模擬通信で、定期保存、連続編集の集約、保存結果不明時の非再送、保存失敗時の終了拒否、終了時の保存を検証します。実サーバーには接続しません。
`KimaiBlocks.exe --render` はGUIを開かずに `preview.png` を生成します。

5分の枠が操作しにくい場合は、上部の「標準」を「拡大」に切り替えてください。旧版の接続先キャッシュと接続設定を引き継ぎます。配布する場合は実行ファイルだけでなく、distフォルダ全体をコピーしてください。
