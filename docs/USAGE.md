# 操作ガイド

[READMEへ戻る](../README.md) · [設定・配布](CONFIGURATION.md) · [集計](REPORTS.md)

## Kimai接続

1. 右上の「メニュー → 接続・データ → アカウント・接続設定」をクリックします。
2. 「追加」または既存行の「編集」でKimaiのURL（例: `https://kimai.example.com`、サブディレクトリにも対応）を入力します。HTTPのテスト環境では「この接続先でHTTPを許可」をチェックします。URLを変更するとチェックが外れます。
3. Kimaiのユーザープロフィールで作成したAPIトークンを入力します。旧版のみ「旧認証方式」を選びます。通常のログインパスワードは使いません。
4. 一覧で接続先を選び「選択したアカウントで保存して接続」で、自分の週の実績とアクセス可能なプロジェクト・アクティビティを取得します。

接続後の追加・移動・サイズ変更・詳細編集・削除は、既定で60秒ごとにまとめてKimaiへ保存します。同じ実績への連続編集は最後の状態だけを送信し、未送信の作成を削除した場合は通信しません。保存間隔は設定で10〜3600秒に変更できます。削除は確認付きです。「今すぐ保存」、週の切り替え、再読込、終了時にも未保存分を保存します。未変更時の定期通信はありません。「再読込」は一覧キャッシュも更新します。フォルダ分類・表示選択・お気に入りはこのクライアントの設定です。

- 時刻は **Kimaiユーザーのタイムゾーン** で表示・入力します。Windowsの時刻設定へは変換しません。
- 未来の実績も送信できますが、Kimai側の設定・権限で拒否された場合はエラーになります。
- プロジェクトとアクティビティにはIDを併記して、同名の項目を区別します。共通アクティビティは利用可能なプロジェクトに表示します。
- エクスポート済み、計測中、休憩付き、日またぎ、5分単位以外の実績は読み取り専用です。変更はKimai側で行ってください。日またぎは日ごとに分割表示します。計測中は開始位置に5分の目印で表示し、ライブ計測はしません。
- 読み取り専用レコードを含む週合計は画面上のブロック長の合計です。休憩・秒単位・計測中の正確な集計はKimaiで確認してください。
- 編集前にサーバー上の主要項目と比較します。ただし比較後から更新までの同時編集を完全に排他制御するものではありません。
- 保存失敗時はエラーダイアログを表示し、未保存変更を保持して定期保存を一時停止します。保存できるまで通常の終了を阻止します。「今すぐ保存」または「再読込」で復旧してください。起動・読込失敗時もダイアログを表示し、「再読込」で再試行できます。
- サーバーで成功して応答だけ失われた可能性がある場合は自動再送しません。「再読込」で照合し、判定できない場合はユーザーに再送の確認を求めます。強制終了やOS停止を完全に阻止するものではありません。送信途中の情報もキャッシュに記録します。
- HTTPSを既定とし、明示的に許可した接続先だけHTTPも使えます。HTTPではトークンとデータが暗号化されません。自己署名証明書を無条件に許可せず、リダイレクト先への認証情報の転送もしません。

## アカウント切り替え

「メニュー → 接続・データ → アカウント・接続設定」のアカウント一覧で接続先を管理します。

1. 「追加」で表示名・Kimai URL・ユーザー名・APIトークンを登録します。別サーバーも登録できます。
2. 既存の行は「編集」またはダブルクリックで変更できます。トークンは一覧では伏せ字、編集画面では表示されます。
3. 接続する行を選び「選択したアカウントで保存して接続」を押します。追加・編集・削除もこの時点で保存されます。「キャンセル」では一覧変更を破棄します。
4. 次回起動時は最後に保存したアカウントへ自動接続します。旧形式の接続設定は1件目のアカウントへ自動移行します。

Bearer認証ではAPIトークンが実際の接続ユーザーを決定します。表のユーザー名は管理用で、旧認証方式の場合のみ認証にも使用します。接続後の画面上部にはアカウント表示名とサーバーが返したユーザー名を表示します。

未保存の実績がある間は切り替えません。設定を閉じて「今すぐ保存」を完了してください。切り替え時には前の画面をクリアし、実績・フォルダ・表示選択などはURLと認証済みユーザーIDごとのキャッシュから読み込みます。同じユーザーへの複数の登録は同じキャッシュを共有します。保存周期・休日・土日表示などのアプリ設定は共通です。

「一覧から削除」は接続設定の登録だけを削除します。Kimai側のユーザー・APIトークン・実績や、既存のアカウント別キャッシュは削除しません。


## 表示プロジェクトと検索

「表示プロジェクトを選択」でチェックを変更し、OKで確定します。キャンセル・Esc・右上の×では破棄します。初回取得・新しく見つかったプロジェクトはチェックなしです。

- チェック済みを先頭へ並べるのは開いたときと検索時だけです。チェック操作中は並べ替えません。
- 右下の「すべてのチェックを外す」は確認付きで、検索対象外も含めて解除します。OKまでは反映しません。
- プロジェクト・作業・履歴の検索は、かな、全半角、英字の大小、空白の違いを吸収します。誤字は推測しません。
- 実績編集のプロジェクト欄は候補を選んで確定します。変更先でも同じアクティビティが選べる場合は保持します。
- グローバルアクティビティが有効と確認できないプロジェクトには、専用アクティビティだけを表示します。

## カレンダーへの入力

- 空きセルをクリックすると5分の1セルを選択します。下半分のクリックも同じセルを対象にします。
- 縦にドラッグして範囲を選択し、その範囲内に作業をドロップすると選択した長さで作成します。範囲外へのドロップはその位置から作成します。
- プロジェクト・分類の親見出しをドロップした場合は、アクティビティを選んで配置します。
- 実績ブロックをドラッグして移動、上下端をドラッグして時間を変更します。Ctrlを押して開始するとコピーです。コピー中も元の実績を表示します。
- 重複時間・入力禁止時間は5分単位で除外し、操作対象を短縮・分割します。9〜12時のうち10〜11時が使用済みなら9〜10時と11〜12時になります。空きがなければ変更しません。
- 分割後は独立した実績です。複数件の保存はサーバー側で一括トランザクションにならないため、途中失敗時は未送信分を保持します。
- 時刻を変えないコメント・作業編集では、既存の実績時間を変更しません。

## 選択・編集・表示操作

- Ctrl+クリックで個別に追加／解除、Shift+クリックで時刻順の範囲選択。青い枠と右下の件数で選択を確認できます。選択した複数ブロックをまとめて移動・サイズ変更・Ctrlドラッグコピーできます。Ctrlコピーのプレビュー中も元のブロックを残します。
- 右下でプロジェクト・作業・日付・開始時刻・時間・コメントを編集し、「適用」で保存待ちにします。複数選択時はコメントを一括変更できます。入力中は定期保存を待機します。
- ダブルクリック／Enterの詳細編集はコメントにフォーカス。F2でブロック上のコメント編集、Enterで確定、Ctrl+Enterで改行、Escapeでキャンセルします。コメント編集を抜ける際も適用します。
- ツリーから既存ブロックへドロップすると、時間・コメントを維持してプロジェクトとアクティビティを置き換えます。空き位置へのドロップは新規作成です。
- 左右パネルの境界をドラッグして幅を変更できます。Ctrl+ホイール／メニューの倍率で50～400%に拡大縮小。幅・倍率は保存します。初期設定では土日列を隠し、既存の表示設定は引き継ぎます。
- 作業ツリーのプロジェクト名は `/` 区切りで階層化します。アクティビティ名は設定した正規表現の $1 でまとめ、$2 を表示します。実際のKimaiの名前は変更しません。
- 自動色はプロジェクト名から決まります。標準16色・256色・無制限を選択できます。固定色は優先します。配色の詳細は後述の「安定した自動色」を参照してください。

| キー | 操作 |
| --- | --- |
| Ctrl+S | 右下の入力を適用してサーバーへ保存 |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl+A | 表示中の実績を全選択 |
| Ctrl+C / Ctrl+V | 選択実績をコピー／クリックしたカレンダー位置へ貼り付け |
| Delete | 選択実績を確認して削除 |
| Enter / F2 | 詳細編集／ブロック上のコメント編集 |
| Escape | 選択解除（コメント編集中はキャンセル） |
| Ctrl+＋ / Ctrl+－ | 拡大／縮小 |

テキスト入力中のCtrl+Z・Ctrl+C等はテキスト編集に使います。Undoは直近100操作まで、定期保存後も対応します。保存済みの削除を戻す場合は同じ入力内容の実績を新規作成するため、実績IDなどサーバー管理情報は元と同一にはなりません。週変更・再読込・アカウント変更では履歴をクリアします。保存結果が不明な間はUndoを含む編集を止めます。

## ブロックの表示

全情報が収まる場合はプロジェクト → 時間 → アクティビティ → コメント、小さい場合はプロジェクト → コメントを優先します。ドラッグ中も同じ文字配置です。マウスを重ねると全文・実績ID・操作案内を確認できます。選択中は青枠で表示します。

現在時刻はカレンダーの赤い線と、メニュー左の時計で確認できます。Kimaiユーザーのタイムゾーンで毎秒更新します。

## 休日・休み時間・時間外

「メニュー → 作業・カレンダー → 休日・休み時間・時間外」で設定します。5分単位で `12:00-13:00` のように1行1区間を入力し、日をまたぐ区間は分けて指定します。追加休業日は1行1日、`yyyy-MM-dd` 形式です。祝日は自動取得しません。

暗色表示と入力禁止を個別に選べます。既存実績は触らない限り変更せず、新規作成・移動・時間変更時に入力可能範囲へ調整します。上部の「時間外・休日の入力禁止」で切り替えられます。土日列の表示とは独立しています。

## フォルダとお気に入り

- フォルダの右クリックからサブフォルダ追加、名前変更、上下の並べ替え、最上位への移動ができます。フォルダを別フォルダへドラッグして階層を変更できます。循環する移動はできません。
- フォルダを削除すると子フォルダと所属プロジェクトは一つ上へ移動します。個別作業へのリンクは解除されますが、Kimaiの作業・実績は削除しません。
- 個別のアクティビティをフォルダへドラッグするか「表示する作業を選択…」で、その作業だけを登録できます。登録解除は同じ選択画面でチェックを外します。リンクした作業は、表示プロジェクトのチェックにかかわらず利用できます。
- お気に入りはツリー先頭に常設し、プロジェクトや分類の階層を挟まず一覧表示します。表示プロジェクトのチェックにかかわらず、有効なお気に入り作業を表示します。追加・削除・移動は不要です。
- 左ツリーのプロジェクトや分類は初期状態で閉じ、利用者が開閉した状態を保存します。罫線で階層を示します。
- 保存・再読込は上部のアイコンから操作できます。
- 実績の新規作成・コピー後、引き伸ばしによるコピー・分割後は選択を解除します。Ctrlを押して上下端をドラッグすると、元の実績を残して伸ばした先の空き時間へコピーします。
- 選択中の実績は、同じプロジェクト・同じコメントを持つブロックの日合計と週合計を右の編集欄上部に表示します。複数選択時は最大6種類まで表示します。
- 時間目盛りは文字が重ならない間隔で60／30／15／10／5分に切り替わります。Ctrl+ホイールは連続した倍率変更をプレビューし、操作が止まってから画面と設定を確定します。


フォルダのドラッグでは、移動先の中央にドロップするとその中へ移動し、上端・下端へのドロップで前後に並べ替えます。「未分類」へのドロップで最上位へ戻せます。土日・日・週の切り替えは上部ボタンに統一しました。既存のお気に入り一覧フォルダは常設のお気に入りに統合します。子フォルダ・個別作業などを持つ旧フォルダは通常フォルダとして残します。

## アクティビティ一覧の正規表現による分類

「メニュー → 表示・作業ツリー → 表示・分類設定」の「アクティビティの分類」で正規表現を指定し、保存すると反映されます。第1キャプチャグループ（$1）が一致する項目を同じ親にまとめ、第2グループ（$2）を子の表示名にします。分類は各プロジェクト内に適用します。

- 標準値 `(.*)/(.*)`：`aaa/xxx`、`aaa/yyy` → 親 `aaa` の下に `xxx`、`yyy`。
- この式は最後の `/` で区切るため、`aaa/bbb/xxx` → 親 `aaa/bbb`、子 `xxx`（親をさらに分割しません）。
- 最初の `/` で区切る場合は `^([^/]+)/(.*)$` を指定します。
- 空欄で分類を無効にします。マッチしない項目、$1または$2が空の項目は元の名前で表示します。
- 元の名前とKimaiのIDは変わらず、検索・お気に入り・ドラッグには元のアクティビティを使用します。
- 不正な式やキャプチャグループが不足する式は設定保存時にエラー表示します。マッチ処理が制限時間を超えた場合は残りを元の名前で表示します。

配布用 `defaults.json` の `ActivityGroupingPattern` でも指定できます（例：`"ActivityGroupingPattern": "(.*)/(.*)"`）。保存済みの値は保持し、既存設定に項目がない場合はこの初期値を使います。JSONでバックスラッシュを書くときは `\` とします。

## プロジェクトの自動色・固定色

「表示・作業ツリー → プロジェクトの固定色」の上部で固定16色（標準）、固定256色、無制限から選択します。自動色はプロジェクト名をもとに決まり、IDや表示順、表示対象の増減には依存しません。同名のプロジェクトは基本的に同じ色になります。

無制限では「既存色と重なる場合は近縁色を割り当てる」を有効にできます。重複時の割当はアカウントのキャッシュに保持し、ほかの項目の表示変更で色が揺れないようにします。「自動色の設定を保存して再設定」は選択した設定を保存して自動色だけを再計算し、手動で固定した色は維持します。16色・256色では重複を許容します。

配布用 defaults.json でも `ProjectPalette`（16、256、0=無制限）と `AvoidColorCollisions`（true/false）を指定できます。

## 履歴・定型入力と表示期間

- 左パネルを「作業」「履歴」「定型」のタブで切り替えます。「履歴」は同じプロジェクト・作業・コメント・長さの重複をまとめて最大100件を保持します。サーバーから読み込んだ実績も空いている履歴枠に補います。履歴はアカウント別のキャッシュに保存します。
- 履歴・定型のカードをカレンダーへドラッグすると、プロジェクト・アクティビティ・コメント・長さを再利用できます。先に時間範囲を選択した場合は、その長さを優先します。既存ブロックへドロップした場合は時間を保持して、プロジェクト・作業・コメントを置き換えます。入力禁止時間と重複時間は通常の作成と同様に除外します。
- 実績の右クリック →「定型入力に登録…」、履歴カードの右クリック、または「定型」タブの登録ボタンから、繰り返す入力を名前付きで保存できます。定型カードの右クリックで名前変更・削除ができます。自動で定期登録は行いません。
- 履歴・定型の検索は、かな・全半角・空白の違いを吸収します。無効なプロジェクト・アクティビティは表示しません。
- 「★ お気に入りのみ」では常設のお気に入り一覧に加え、該当作業がある未分類・フォルダ・プロジェクトを元の階層で表示します。該当作業がない枝は隠し、切り替え時に親項目を自動展開せず開閉状態を維持します。「表示プロジェクト」は開いたときと検索時にチェック済みを先頭、その中を名前順で表示します。チェック操作中は並べ替えません。
- 上部「期間…」で開始日・終了日を指定できます。両端を含めて最大31日、1日の幅は100〜400pxです。期間表示は土日を含む連続日付で、下部の横スクロールで移動します。日付見出しも連動します。「週」で通常の週表示に戻ります。同じ期間の列幅変更では通信しません。
- 期間切り替え前には未保存変更を保存します。キャッシュには選択期間と列幅も保持します。週集計のため、取得範囲は両端の週を含めます（最大42日）。右の週集計は選択した日が属する週を集計し、上部は指定期間の合計を表示します。
- 上部「先週と比較」は、表示週（期間表示では統計で選んだ日の週）とその前週を別画面で左右に並べます。元の実績は編集せず、先週からコピーできます。土日を含む7日表示です。縦スクロールが連動し、ホバーで実績詳細を確認できます。先週はサーバーから取得し、表示週には現在の未保存編集を含みます。

### 先週のブロックをコピー

「先週と比較」の左側でブロックをクリックすると青枠で選択されます。Ctrl+クリックで複数選択、Shift+クリックで開始時刻順の範囲選択ができます。

1. 「コピーして戻る」を押します（Ctrl+C／「コピー」も使用可能。その場合は画面を閉じてください）。
2. メイン画面で貼り付け先の日時をクリックします。
3. Ctrl+V または上部の貼り付けボタンで配置します。

先頭ブロックが指定位置に配置され、複数ブロック間の日付・時間差、プロジェクト、アクティビティ、コメント、長さを引き継ぎます。先週の実績は変更せず、新しい実績として通常の定期保存対象になります。重複・入力禁止時間を除外し、Ctrl+Zで取り消せます。全ブロックがメイン画面の表示範囲内に収まる位置を指定してください。日をまたぐ実績・5分単位以外の実績や、現在利用できないプロジェクト・アクティビティはコピー対象にできません。

## プロジェクトの追加

「メニュー → 作業・カレンダー → プロジェクト追加」で、顧客・名前・説明・表示フォルダを指定します。グローバルアクティビティを有効にして作成します。確認チェックと2回の確認後、定期保存を待たずサーバーに送信します。必要な権限は[設定ガイド](CONFIGURATION.md)を参照してください。

## 保存失敗からの復旧

未保存変更を残して「今すぐ保存」「再読込」で復旧できます。結果不明の送信は自動再送しません。「未保存変更を破棄」は確認後に残ったローカル編集を破棄しますが、サーバーが受け付けた変更は戻しません。

「接続・データ → バックアップを破棄してサーバーから再取得」は、現在アカウントの実績・一覧キャッシュを取得し直します。失敗時は未保存変更を保持します。表示選択・フォルダ・接続設定は保持します。
