# 集計ガイド

## カレンダーの日・週・コメント集計

右パネルは「週」「日」タブで集計を切り替え、下部で選択実績を編集できます。日集計はプロジェクト → コメントの階層 → アクティビティ → 実績のツリーで内訳を確認できます。プロジェクトとコメントは初期状態で展開し、折りたたみも可能です。詳細は「コメント別の詳細集計」から開き、週全体／日別を切り替えます。

- プロジェクト → コメントの階層 → アクティビティ → 実績
- `aaa/xxx` と `aaa/yyy` は `aaa` の下に `xxx` と `yyy` を表示します。別プロジェクトのコメントはまとめません。

各階層に合計時間・件数を表示します。空のコメントは「コメントなし」にまとめます。前後の空白と改行コードを揃えて比較し、それ以外の表記差は別グループにします。未保存・未来・非表示曜日の実績も含む表示週の集計で、重複時間も加算します。

## サーバー実績集計（全ユーザー）

「メニュー → 集計 → サーバー実績集計（全ユーザー）」で開始日・終了日または全期間を選び、「取得して集計」を押します。今日を含む週を初期期間にします。サーバー保存済みの実績を読み取り専用で取得し、ローカルの未保存変更は含めません。請求情報は表示しません。

| テーブル | 主な表示 |
| --- | --- |
| ユーザー入力状況 | 実績件数、開始日基準の入力日数、時間、計測中件数、時間不明件数、最初／最後の開始日時 |
| プロジェクト合計 | 閲覧可能な全ユーザーの件数・人数・時間 |
| プロジェクト×ユーザー | プロジェクト内のユーザー別件数・時間 |
| プロジェクト×アクティビティ | プロジェクト内の作業別件数・人数・時間 |
| 実績明細 | 実績ID、プロジェクト、ユーザー、作業、開始／終了、時間・秒数、状態、コメント |
| アクティビティ別 | 作業ごとの横断集計 |
| 月別 | 開始月ごとの件数・人数・時間 |
| プロジェクト×コメント | プロジェクト内の同じコメントごとの件数・人数・時間 |

列見出しで並べ替え、検索欄で表示中のテーブルを絞り込み、行選択してCtrl+Cで表をコピーできます。検索は表示行を絞るもので、合計を再計算する条件ではありません。

### 取得範囲と権限

他人の実績には `view_other_timesheet` と対象へのチームアクセス権が必要です。ユーザー一覧には `view_user` が必要です。`api_access` も引き続き必要です。ロール名から権限を推測せず、APIが許可した結果を使います。

Kimai 2.67では `user=all` を指定しても他人の実績権限がない場合は本人分だけが返されます。したがって画面には「閲覧を許可された範囲」と明記します。ユーザー一覧が403の場合は本人と取得実績内のユーザーIDで表示します。0件は「取得0件（未入力とは断定不可）」であり、未入力者・欠勤者の確定一覧ではありません。入力日数も勤務予定や入力完了を判定するものではありません。

期間は接続ユーザーのタイムゾーンで**開始日時**に適用し、終了日の23:59:59を含みます。期間外に開始した実績は含まず、期間内に開始して期間外に終了した実績は全時間を集計します。全期間は日付条件を付けません。時間はKimaiの `duration` 秒を集計し、休憩を再控除したり5分に丸めたりしません。計測中・duration不明は件数に含め、時間合計からは除外します。サーバーに登録された重複・未来の実績も対象です。

取得中は進捗を表示しキャンセルできます。ページを順番に取得し、通信失敗・取得上限（50万件）・ページ取得が進まない場合は部分集計を表示しません。集計データはこのダイアログのメモリ上だけに保持します。取得中に他のユーザーが更新した場合、同時点のスナップショットにはならないため必要に応じて再取得してください。

参照: [Kimaiの実績APIと権限制御](https://github.com/kimai/kimai/blob/2.67.0/src/API/TimesheetController.php)、[ユーザー一覧API](https://github.com/kimai/kimai/blob/2.67.0/src/API/UserController.php)。

### 他メンバーの表示

「サーバー実績集計」で期間を取得後、「メンバーを選択」で検索付きチェックリストから対象を選びます。選択したメンバーだけで全テーブルを再集計します。全解除は0人で、全員には戻りません。フィルタは取得済みデータに適用し、追加のAPI通信は行いません。

「日／週のブロック表示」では、1日をメンバーごとの列で比較するか、1週間をユーザー切替で閲覧できます。重複実績は横に並べ、日またぎは日ごとに分割表示します。日付／ユーザー／倍率を切り替えられ、土日表示は本体設定に従います。ヘッダーは固定し、人数が多い場合は横スクロールできます。閲覧専用で、自分の編集対象とは分離しています。

表示できるのは取得した期間・権限範囲内の実績です。開始日時が取得期間より前の実績は取得対象外です。枠の高さは開始～終了の経過時間、表の集計はKimaiのdurationです。計測中は仮の5分枠を表示し、確定時間には加えません。

### 日別入力状況・明細・複数期間の集計

- 「サーバー実績集計」の「メンバーを選択」で対象を絞れます。「集計の設定」または `defaults.json` / `settings.override.json` の `ExcludedReportUserIds`（KimaiのユーザーIDの配列）で常に除外するユーザーを設定できます。
- 「日別入力状況」はユーザーが縦、日付が横です。初期期間は今日の週。「開始日の月」で1か月分に切り替えられ、横スクロールで閲覧できます。前月・翌月ボタンは1か月ずつ移動して自動取得します。日別セルは30px幅、見出しは日だけの2桁表示です。値は小数1桁まで表示し、ホバーで日付と詳細時間を確認できます。日別表は最大31日で、各日の時間が `ReportMinimumHours`（標準8時間）未満なら赤表示します。休日も同じ基準です。期間合計も表示します。
- 「プロジェクト実績明細」は「明細のプロジェクト」で複数選択でき、全期間または開始日・終了日で取得します。プロジェクト名、アカウント名、日付、開始・終了時刻、時間（小数）、分、アクティビティ名を表示します。「選択中表CSV」で表示中の表をUTF-8（BOM付き）で保存します。
- 「プロジェクト別複数期間」で、縦軸がプロジェクト、横軸が期間名の表で設定します。交点を選んで上の入力欄から期間を設定・更新できます。期間名を編集して「期間名を変更」で列全体を改名できます。「開始からすべて」「以降すべて」で各端の日付を省略でき、両方チェックすると全期間です。結果はプロジェクト別の期間合計を標準表示し、アクティビティ別はタブで切り替えます。プロジェクトによって異なる日付範囲を指定できます。対象ユーザーの絞り込みとCSV出力にも対応します。
- 複数期間の設定は保存して次回に復元できます。「設定をインポート／エクスポート」でJSONファイルとして移行できます。[期間設定例](project-periods.example.json)のURLとプロジェクトIDを実際の値に変更してください。サーバーが異なる設定は混用しません。
- 集計は接続ユーザーのタイムゾーンの実績開始日で区分し、終了日を含みます。計測中・作業時間不明の実績は時間合計に含めません。期間が重なると同じ実績を各期間に計上し、合計列は期間列の和になります。日別の赤表示は入力時間の目安です。
- CSVは現在の表示・ユーザーフィルタを反映し、表計算ソフトで数式と解釈される先頭文字には引用符を付けます。集計の除外ユーザー設定は全ユーザー集計と複数期間集計の両方に適用します。



集計設定の保存は、接続設定とは独立して行い、保存済みAPIトークンの形式移行は実行しません。除外ユーザーIDは全角数字・カンマ・空白・改行に対応します。取得後は一覧からも選択できます。保存失敗時はファイル処理などの具体的なエラーを表示します。

期間設定JSONの `From` / `Through` はそれぞれ `null` で下限／上限なしを表します。既存の日付付き設定ファイルも引き続き読み込めます。

複数期間の設定表はヘッダーをクリックして昇順・降順に並べ替えられます。列名は編集可能なプルダウンから既存名を選択するか、新しい期間名を入力してください。
