# Kimai Blocks

<img src="Assets/KimaiBlocks.png" width="96" alt="Kimai Blocks icon">

Kimaiの実績を5分刻みのタイムブロックで管理する、Windows向け非公式クライアントです。C# / WPF / .NET 10で実装しています。

## 主な機能

- 日・週・指定期間のカレンダーで、実績の作成・移動・サイズ変更・コピー
- プロジェクト検索、アクティビティの階層表示、フォルダ、お気に入り、履歴・定型入力
- 複数アカウント、起動時の接続、定期保存、終了時保存、ローカルキャッシュ
- 休日・休み時間・時間外の表示と入力制限
- 日・週の統計、コメント別集計、ユーザー別・プロジェクト別・複数期間の集計、CSV出力

## 必要環境

- WindowsでWPFを実行できる環境
- 実行時：.NET 10 Desktop Runtime（ランタイム同梱版では不要）
- 開発時：.NET 10 SDK
- アクセス可能なKimaiサーバーとAPIトークン

Kimai 2.67.0で基本的な実績CRUDを確認しています。全バージョン・独自設定での互換性を保証するものではありません。

## ビルドと初回起動

リポジトリのルートでPowerShellを開きます。

```powershell
./Build.ps1
./dist/KimaiBlocks.exe
```

初回ビルドにはNuGetからの依存パッケージ取得が必要です。配布時は実行ファイルだけでなく、`dist` フォルダ全体をコピーしてください。ソースZIPにビルド済みバイナリは含まれません。

1. 初回のアカウント画面で「追加」を押します。
2. 表示名、Kimai URL、APIトークンを入力します。通常のログインパスワードは使いません。
3. 一覧でアカウントを選び「選択したアカウントで保存して接続」を押します。
4. 「表示プロジェクトを選択」で対象をチェックし、OKで確定します。
5. 左のアクティビティをカレンダーにドラッグして実績を作ります。

次回から保存したアカウントへ自動接続します。保存間隔は標準60秒です。保存に失敗すると変更を保持し、通常の終了を中止します。

## 保存データと主な制限

設定とキャッシュは `%LOCALAPPDATA%/KimaiBlocks` に保存します。APIトークンはAES-GCMで暗号化し、鍵は同じフォルダの `token.key` に保存します。**フォルダと鍵を入手した人はトークンを復号できます。** 実績キャッシュは平文です。これらのデータをリポジトリへ追加しないでください。

- 管理者でなくても利用できます。必要な権限とチーム割当は[設定ガイド](docs/CONFIGURATION.md)を確認してください。
- 計測中・エクスポート済み・休憩付き・日またぎ・5分単位以外の実績は読み取り専用です。
- ドラッグ中の自動スクロールは未実装です。
- 同時編集の確認は行いますが、サーバーとの完全な排他制御はありません。
- カレンダー統計はブロック時間、サーバー集計はKimaiのdurationを使います。
